# Host a Static Website with GitHub Pages

## Objective
Deploy a static HTML/CSS website using GitHub Pages.

## Deliverables
- **Live Website:** https://nagakrupa12.github.io/devops-git-workflow/
- **GitHub Repository:** https://github.com/nagakrupa12/devops-git-workflow

## Steps Implemented
1. Created `index.html` and `style.css` locally.
2. Initialized Git, committed changes, and pushed to GitHub.
3. Enabled GitHub Pages under Repository Settings deploying from the `main` branch root folder.
4. Verified the live static site deployment.
